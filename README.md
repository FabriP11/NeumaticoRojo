# 🏎️ Neumático Rojo

**La Fórmula 1, vuelta a vuelta y dato a dato.**

Plataforma web de resultados y estadísticas de Fórmula 1. Un proyecto personal desarrollado para consultar calendarios, clasificaciones, resultados e información de pilotos y escuderías desde un solo lugar.

### 🌐 Visitar la web

**[Neumático Rojo — Versión Beta](https://neumaticorojo-production.up.railway.app/)**

La plataforma es de acceso público para consultar estadísticas y resultados. El registro de usuarios está disponible únicamente mediante código de invitación.

### 🏁 Funcionalidades

- Calendario de Grandes Premios y sesiones.
- Resultados de carreras, clasificaciones, sprints y prácticas libres.
- Clasificaciones de pilotos y constructores.
- Estadísticas de temporadas desde 2020.
- Cuentas de usuario con pilotos y escuderías favoritos.
- Diseño adaptable con modos claro y oscuro.

### 🛠️ Tecnologías

**Frontend:** React, Vite, JavaScript y Tailwind CSS.

**Backend:** Node.js y Express.

**Base de datos:** MySQL.

**APIs:** Jolpica F1 API y OpenF1.

**Despliegue:** Railway.

### 🚧 Estado del proyecto

**En desarrollo.** La versión beta está disponible públicamente y continuará recibiendo mejoras, correcciones y nuevas funcionalidades.
